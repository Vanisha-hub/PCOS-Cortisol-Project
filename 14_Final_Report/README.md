# Final Project Reports

This folder contains the **final compiled reports and thesis-style documents** generated from the *PCOS–Cortisol Project*. These reports integrate results from all upstream analyses, including transcriptomics, differential expression, pathway enrichment, and biological interpretation.

##  Folder Contents

### Integrated Transcriptomic Analysis Reports
- **Integrated_Transcriptomic_Analysis_of_PCOS_*.pdf / .docx**
  - Comprehensive integration of multi-dataset transcriptomic analyses
  - Includes RNA-seq and microarray-based differential expression results
  - Covers pathway enrichment (GO, KEGG), biological interpretation, and discussion
  - Suitable for academic submission, evaluation, or manuscript preparation

###  Final Project Report
- **PCOS_MultiDataset_Analysis_FinalProject_2025_* **
  - Consolidated final report summarizing:
    - Dataset acquisition
    - Preprocessing and quality control
    - DEG identification
    - Cortisol-related gene integration
    - Functional enrichment analyses
  - Represents the final outcome of the complete computational pipeline
